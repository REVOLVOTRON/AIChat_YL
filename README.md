# AIChat_YL

Учебный набор экспериментов с функциями ИИ: генерацией текста и изображений, распознаванием речи и изображений, переводом и другими сценариями.

## Структура
- features_test_files/ — демонстрационные сценарии
- api_inf/ — локальная конфигурация API
- scripts/ — вспомогательные модули
- saved_images/, user_info/, cache/ — каталоги данных приложения

Проверьте зависимости и точку входа в исходниках перед запуском. Конфигурацию API и пользовательские данные храните локально, вне публичного Git.

## Статус
Экспериментальный проект; часть модулей является заготовками.
